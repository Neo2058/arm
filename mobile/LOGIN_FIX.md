# Ошибка входа Android: TLS и учётные данные

Дата: 2026-10-23. Код и конфигурация production не изменялись; выполнены тестовые запросы авторизации.

## Подтверждено на сервере

- `https://xn---15-7edz.xn--p1ai/api/mobile/me`: TLS hostname mismatch, curl error 60.
  Сертификат не покрывает домен без www. Мобильный HTTPS-запрос обрывается ещё до HTTP/проверки пароля.
- `https://www.xn---15-7edz.xn--p1ai`: сертификат проходит проверку; с Accept: application/json mobile API отвечает JSON.
- Первый вход с первоначально предоставленными данными в mobile API на www получил HTTP 422 «Неверные учётные данные».
- Сравнение через новую web-сессию с CSRF/cookies тоже вернуло на `/login`; `/mainMenu` потребовал авторизацию.
  Пользователь уточнил, что браузер использует сохранённую сессию/автозаполнение, затем исправил пароль.
- С уточнённым паролем mobile login на www успешен (HTTP 200). `/me`, `/documents`,
  `/training/topics` вернули HTTP 200 и JSON. Проверка выполнена прямыми HTTPS-запросами с компьютера.
- Тестовый токен отозван через `/logout` (HTTP 200); последующий `/me` с ним получил HTTP 401.
  Пароль и токены в репозиторий не записывались. Тестовые web cookies удалены.

## Исправления клиента (версия 1.0.2, Android versionCode 3)

- Канонический API URL с www установлен в app.config.js, eas.json, .env.example и fallback клиента.
- Общий api-config.cjs нормализует старые HTTPS адреса production до www до отправки запроса,
  включая старое EXPO_PUBLIC_API_URL. Пользовательские адреса тестовых серверов сохраняются.
- TLS-проверка остаётся включённой. Отключение проверки сертификата не требуется.
- Сообщения различают отсутствие защищённого соединения, 401/422, 403, 429, 5xx и ошибку SecureStore.
- Ответ login проверяется на наличие token/user перед сохранением; HTML или неожиданный JSON не считается входом.
- Исправление native expo-av crash из 1.0.1 сохранено; подписанный APK нужно переустановить.

- Артефакт: `mobile/android/app/build/outputs/apk/release/app-release.apk`.

- Раздаваемый `public/downloads/tch15-android.apk` не заменён.
