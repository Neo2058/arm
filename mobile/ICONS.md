# Иконки — версия 1.0.8

Обновление: иконки впервые публикуются вместе с мобильной привязкой Telegram в **1.0.9 (10)**.
Версия 1.0.8 ниже описывает предыдущую локальную сборку, которая на сервер не выкладывалась.

Работа с финансовыми формулами отложена до подготовки владельцем правил оплаты и контрольных примеров.
В этой итерации обновляются только мобильные иконки и ресурсы бренда; веб-карусель и API не меняются.

## Интерфейс

Общий компонент `src/components/AppIcon.js`: локальные SVG-контуры, без удалённых шрифтов.
react-native-svg 15.15.4 соответствует bundledNativeModules Expo SDK 57.

- Вкладки: документы, тесты, наряды, обучение, профиль, поручения инструктора.
- Карточки: документы, темы/материалы, тесты, наряды, поручения.
- Действия: телефон, вход/выход, повторный вход, отправка, play/pause, вложение, открытие PDF,
  журнал инструктора, задачи и бригада. Текстовые подписи сохранены.
- Декоративные SVG скрыты от screen reader; кнопка телефона в заголовке имеет подпись и hitSlop.
- Active/inactive состояния используют существующие цвета навигации; active имеет более плотный контур.

## Значок приложения

Редактируемые оригиналы: assets/app-symbol.svg и app-symbol-monochrome.svg.
Знак — оранжевый поезд «15» на тёмном фоне, рельсы и холодный светлый акцент.
Отдельные PNG для обычной иконки, adaptive foreground/background, monochrome, splash и favicon.
Foreground имеет прозрачный фон и отступы под маски Android. Ресурсы не запрашиваются из сети.

Перегенерация на macOS:

```bash
swift mobile/scripts/render-app-icons.swift /absolute/path/to/mobile/assets
# Для существующего локального native-проекта, без prebuild и изменения подписи:
swift mobile/scripts/render-app-icons.swift /absolute/path/to/mobile/assets --android-res
```

На другом build host используются готовые PNG из git. Не запускать prebuild --clean ради иконок:
это может удалить локальную настройку release signing.

Обновление требует native APK: добавлен react-native-svg и изменены launcher resources.
Версия 1.0.8, Android versionCode 9; нативный iOS-бинарник этой итерацией не собирается.

## Проверки

- 20 существующих JS-тестов прошли; iOS JS-export успешен.
- Android release для arm64-v8a и armeabi-v7a собран; сертификат совпадает с утверждённым.
- В эмуляторе проверены установка поверх имеющегося приложения, холодный запуск,
  отображение SVG на экране входа; crash-буфер пуст.
- Общий новый launcher icon просмотрен; adaptive-слои имеют прозрачный foreground,
  основной PNG 1024×1024 — RGB без alpha, monochrome — RGBA.
- Авторизованные экраны и все вкладки на физических устройствах ещё требуют визуальной проверки.
- Локальный артефакт: `mobile/artifacts/tch15-1.0.8.apk`. Он не добавляется в git.
  На production APK не заменялся, коммиты этой итерации ещё не опубликованы.

## Профиль и Telegram — 1.0.9

ProfileScreen показывает статус привязки и кнопки привязать/открыть бота/отвязать/обновить статус.
Используются GET/POST/DELETE `/api/mobile/account/telegram`, тот же TelegramAccountLinker,
Sanctum и active user; ссылки no-store, только в памяти клиента, выпуск/отвязка ограничены throttle.
После возврата из Telegram статус обновляется. Внизу прокручиваемого профиля виден номер версии.

Проверки: 374 PHP-теста / 1844 assertions; 20 mobile JS-тестов. Изолированный native UI-стенд
с подменённым API подтвердил вкладки, SVG и кнопку Telegram; после прокрутки видна версия 1.0.9.
Production App.js восстановлен перед финальной сборкой; тестовый маркер отсутствует в её Hermes bundle.
Подлинная отправка команды настоящему боту требует проверки пользователем после установки.
