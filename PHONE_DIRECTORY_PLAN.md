# Общий справочник телефонов

План согласован 2026-10-26.

- [x] PostgreSQL: общая таблица, уникальный нормализованный номер, перенос картотеки с отчётом конфликтов.
- [x] Общие API для активных пользователей, ограничение добавления.
- [x] APK и веб-вкладка, явный перенос браузерных контактов.
- [x] Тесты дубликатов, доступа, поиска и регрессий.
- [ ] Новый APK, резервная копия, публикация и проверка публичного файла.

Событие phone.created: ID записи и автора без ФИО и телефона. Финансовый блок отложен.

## Перенос и ограничения

`php artisan phones:import-personnel` проверяет действующую картотеку без записи;
`php artisan phones:import-personnel --apply` переносит корректные номера. Повторный запуск безопасен.
Варианты 8/7/10 цифр приводятся к +7, международные принимаются с + и кодом страны.
Неполные/неверные номера не угадываются: команда сообщает ID кадровой записи и поле.
Конфликтующие ФИО также выводятся через ID без телефона: уже существующий владелец записи
в общем справочнике сохраняется; кадровая картотека не меняется.
Номера сохраняются как самостоятельные контакты: последующее увольнение не удаляет их автоматически.
Отредактированные кадровые телефоны не перезаписывают пользовательские контакты.

Массовая очистка общего справочника и пользовательские изменение/удаление отсутствуют.
Отдельные административные экраны исправления/удаления требуют согласования phone.updated/deleted;
до этого исправления выполняются администратором в контролируемой операции с резервной копией.
Пользователи видят предупреждение об общей доступности ФИО и телефона перед сохранением.
