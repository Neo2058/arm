## Границы защиты

Расположение APK не заменяет авторизацию: каждый API-запрос проверяет актуальные права. Секретов Grafana/SSH/БД в APK нет. Снимок содержит только фиксированные агрегаты, без пользовательских данных и сырых журналов. Обновление каждые 30 секунд в активном приложении; старше 120 секунд отмечается как устаревшее. При ошибке сети предыдущие значения скрываются. Полное отключение production делает мобильную панель недоступной; независимый внешний наблюдатель остаётся отдельным этапом.

Нельзя запускать мониторинг с базовым compose вместо действующих security/runtime/readonly overlays. `docker-compose.monitor-mobile.yml` добавляется последним к текущему COMPOSE_FILE.
