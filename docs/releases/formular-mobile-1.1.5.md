## Изменения

- Общий FormularService для мобильного Sanctum API и веба; машинист вносит запись по активному заданию, инструктор своей колонны подтверждает либо возвращает с замечанием.
- Полный список и статистика, включая ещё не внесённые записи; фильтры сотрудника/задания/статуса и страницы по 25 строк.
- Только driver/instructor для собственных записей; контроль только instructor и активные driver своей текущей непустой колонны. Самопроверка запрещена.
- Статусы pending/confirmed/returned, версия и UUID-квитанции в одной транзакции. Старые записи получают pending; прежний POST веба не может перезаписать подтверждённую запись.
- Локальный черновик и замороженный запрос до отправки; ручной повтор, перевход сохраняет, явный выход удаляет и блокирует поздние ответы.
- Согласованные события ClickHouse `formular.review_confirmed` и `formular.review_returned`; `formular_logged` переиспользован с resource_id задания. Только идентификаторы, без текста записи/замечания. Схема аналитики, MinIO, расчёты и карусель не меняются.
