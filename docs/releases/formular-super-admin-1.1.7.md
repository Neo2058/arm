# Формуляр: доступ super_admin — Android 1.1.7 / code 23

12.11.2026. Статус: подготовка выпуска; не считать опубликованным до фактических результатов ниже.

Владелец разрешил super_admin пользоваться новыми пользовательскими функциями для самостоятельной проверки. Общий обход авторизации не вводится: разрешения задаются отдельно для каждой функции.

Формуляр: собственные записи и контроль всех колонн для активного super_admin без требования профиля/колонны. Контроль охватывает активных driver/instructor/super_admin, в том числе сотрудников без профиля; собственную запись подтверждать нельзя. Инструктор по-прежнему проверяет только машинистов своей непустой колонны. Обычный admin дополнительных прав не получает. Проверяются актуальные роль/активность, monitor-токены запрещены. UUID, версии и согласованные события аудита сохранены; новых событий, схем и формул нет.

Веб: `/formular`. Android: Профиль → «Формуляр · записи и проверка» → «Все колонны». Росписи инструктажей — следующий отдельный этап, этим выпуском не переносятся. Для них также учитывать разрешение super_admin.

Проверки: FormularTest с глобальным доступом, отсутствующим профилем, запретом самопроверки, отзывом роли/активности и monitor-token; обязательные тесты журнала/файлов/планирования/маршрутов/ролей; Node formular mutations; веб build; подписанный APK и проверка установки/старта.

Миграций нет. Перед выкладкой сохранить backup, прежние APK/manifest, проверить новый SHA; обновить также android-latest.json для автообновления 1.1.6+. MinIO и приватный monitor APK не меняются. Физическая приёмка владельцем остаётся обязательной.
