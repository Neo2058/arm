GET `/api/mobile/quizzes/history?page=1` использует существующие Sanctum, active-user и запрет monitor-token. 20 попыток на страницу, сначала новые. Ответ содержит только ID попытки и теста, название, score, total_questions, time_spent в секундах и completed_at. `has_more` определяет кнопку следующей страницы. Cache-Control: private, no-store. Идентификатор пользователя определяется исключительно токеном; user_id из запроса не используется.

Показаны собственные результаты активных тестов, общих либо с доступным сейчас документом. При изменении прав закрытые тесты исчезают из списка. super_admin видит свои результаты согласно существующим правам; чужие результаты ему не подмешиваются. Удалённые/неактивные тесты не раскрываются. В БД старые попытки сохраняются.

`answers_log`, правильные ответы, ФИО и чужие результаты не выдаются. `is_viewed` не меняется: это поле существующего контроля инструктора. Миграции, формулы оценки и события ClickHouse не меняются. Новых зависимостей нет. Данные остаются в памяти экрана, без дискового кеша. Сетевую ошибку видно и при непустом списке; обновление и повтор доступны вручную. Поздний ответ после ухода с экрана игнорируется.

Дата/название берутся из существующих записей и текущего Quiz; архив редакций этим выпуском не создаётся. Процент и порог «сдал» не придумываются: выводится сохранённое число правильных ответов относительно числа вопросов.
