# Карта покрытия функций — рабочая редакция 09.11.2026

Основание: 350 зарегистрированных маршрутов локального checkout, 31 объявление мобильных экранов/вкладок, 18 Filament-ресурсов. Машинный перечень — ROUTES_INVENTORY.csv, источники/хеши — SOURCE_INVENTORY.json. Это исходный реестр по коду, не доказательство готовности 350 отдельных пользовательских функций и не проверка текущего production.

Обозначения: **К** — найдено в коде, требуется проверка поведения и актуальной публикации; **П** — план развития; **Ч** — частичная готовность/ограничение. Во всех строках финальная запись действий ещё не выполнена. Пробный ролик использует прежние учебные снимки, а не новую сквозную запись.

## Что ещё необходимо для полного покрытия

- [ ] Сопоставить все операции каждой группы с конкретными сценами и результатами действий, включая 18 административных ресурсов.
- [ ] Проверить контроли и платформенные различия по реализациям, не только по маршрутам.
- [ ] Подтвердить актуальные публикации и ручную приёмку, отдельно проверить локальные незавершённые подстройки.
- [ ] Записать сценарии веба/Android на согласованных учебных данных; подтвердить состав/статусы рабочего чата.
- [ ] Сверить раскадровку, тайминги и финальный видеоряд с этим реестром. Маршруты только технического транспорта допускается объяснить общей сценой защиты, но не терять из ведомости.
