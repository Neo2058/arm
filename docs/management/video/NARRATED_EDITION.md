## Повторная сборка

Потребуются сохранённые учебные источники `recordings/`, оригинальный MP3, macOS с Swift/AppKit/AVFoundation и FFmpeg. Модель распознавания не нужна для повторной сборки уже согласованных таймингов.

Из корня репозитория:

```sh
python3 docs/management/video/tools/build-narrated.py
# Выходной файл не должен существовать: рендер отказывается перезаписывать готовое видео.
swift docs/management/video/tools/render-narrated.swift \
  "$PWD/docs/management/video/NARRATED_CHAPTERS.json" \
  "$PWD/docs/management/video/preview/narrated"
python3 docs/management/video/tools/assemble-narrated.py --ffmpeg /path/to/ffmpeg --prores
```

Рендер может требовать доступа к локальному кодировщику macOS. Не запускать генераторы старой редакции поверх авторского NARRATION_CUES.md. Для повторного вывода сначала сохранить предыдущие результаты отдельно; инструменты новой редакции не перезаписывают существующие MP4/MOV.

Тяжёлые видео и промежуточные кадры остаются локальными артефактами. Планы, тайминги и отчёт проверки предназначены для Git. Для After Effects импортировать MOV как видеоматериал со звуком и создать композицию из него; родной `.aep` здесь не создаётся.

## Выполненные проверки

- Оба контейнера: 1920×1080, 30 fps, 616,467 секунды, одна видеодорожка и одна звуковая дорожка.
- В каждом файле декодированы 39 контрольных точек: середины всех 37 сцен, начало и конец.
- В шести фрагментах по всей длине звук сопоставлен с исходным MP3: временной сдвиг не обнаружен.
- MP4 полностью декодирован FFmpeg без ошибок. Для MOV проверены контрольные точки, полного декодирования не выполнялось.
- Проверены размеры текстовых блоков; просмотрены общий контактный лист 37 сцен и отдельный кадр. Полный просмотр со звуком человеком остаётся финальной пользовательской проверкой.
- [Отчёт MP4](preview/ARM_overview_narrated.mp4.verification.json) и [отчёт MOV](preview/ARM_overview_narrated_ProRes.mov.verification.json) содержат параметры, проверки звука и SHA-256.

MP4 занимает около 72 МиБ, ProRes MOV — около 3,3 ГиБ. Больший размер MOV предназначен для удобства монтажа, а не означает появления деталей сверх исходных кадров.
