# Локальный ИИ в АРМ — видеопрезентация

Комплект от 10.11.2026. **6 минут 4 секунды · 1920×1080 · 30 fps · без звука.**

## Что открыть

- **[Анимированное видео MP4](output/ARM_local_AI_silent.mp4)** — готовый видеоряд для записи озвучки.
- **[Текст диктора с таймкодами](NARRATION.md)** — 16 сцен, готовый вариант речи и имена звуковых файлов.
- [Тайминги CSV](TIMING.csv) — начало, конец и длительность каждой сцены.
- [Ресурсы, защита, обучение и этапы внедрения](IMPLEMENTATION.md) — подробности и официальные источники.
- [План сцен](SCENES.json) — источник текстов и длительностей.
- [Проверки видео](VERIFICATION.json).

Видео создано из оригинальной векторной графики средствами AppKit/AVFoundation. Есть движение данных, печатающиеся ответы и документы, сканирование учебного листа, проверка полей и движение карточки задачи. Сторонние изображения и облачные генераторы не использовались.

Разговорная редакция: рассказ построен вокруг повседневных задач сотрудников. Текст озвучки и надписи обновлены; длительность сцен сохранена. Технические условия и этапы внедрения собраны отдельно в IMPLEMENTATION.md.

## Озвучка без After Effects

### Через Finder

1. Открыть [текст озвучки](NARRATION.md). Лучше записывать каждую сцену отдельно, спокойным голосом, с запасом до конца окна.
2. Создать папку для записей. Имена — из CSV: `01-intro.wav`, `02-ui.wav` и далее. Вместо WAV поддерживаются MP3, M4A, AAC, FLAC, AIFF и OGG; на каждую сцену должен быть один файл.
3. Дважды открыть **[Озвучить.command](Озвучить.command)**. Выбрать «Записи по сценам» и папку с файлами. Альтернатива — «Одна дорожка», если вся речь записана под таймкоды одним файлом.
4. Получить `output/ARM_local_AI_with_voice.mp4`. Видео не перекодируется; к нему добавляется звуковая дорожка AAC. Повторный запуск создаёт новый номер файла.

Короткие записи дополняются тишиной до конца сцены. Длинные не ускоряются и не обрезаются: программа сообщает, какую сцену перезаписать. Одна дорожка должна уже соответствовать таймкодам — инструмент не угадывает границы фраз.

На текущем компьютере в `output/tools/ffmpeg` сохранён локальный FFmpeg из временного пакета imageio-ffmpeg. Для запуска также нужен Python 3.9+; здесь доступен `/usr/bin/python3`. Никакой серверный логин, интернет или After Effects для сведения не нужны. Если macOS блокирует запуск файла, его можно выполнить через Terminal командой ниже; системную защиту отключать не требуется.

### Через Terminal

Из корня проекта:

```sh
# Проверить записи, не создавая видео:
python3 docs/management/video/local-ai/tools/mix_audio.py --scene-dir /путь/к/записям --check-only

# Собрать по сценам:
python3 docs/management/video/local-ai/tools/mix_audio.py --scene-dir /путь/к/записям

# Добавить одну готовую дорожку:
python3 docs/management/video/local-ai/tools/mix_audio.py --single /путь/к/озвучке.mp3
```

При отсутствии комплектного FFmpeg можно указать `ARM_FFMPEG=/абсолютный/путь/ffmpeg`. Команды не пересылают записи в сеть. Временные WAV создаются в приватном временном каталоге и удаляются после работы. Исходные файлы не изменяются.

## Повторная сборка видеоряда

На macOS со Swift/AppKit/AVFoundation, из корня проекта:

```sh
# Выходной файл не должен существовать; используйте новый каталог для новой версии.
swift docs/management/video/local-ai/tools/render.swift \
  "$PWD/docs/management/video/local-ai/SCENES.json" \
  "$PWD/docs/management/video/local-ai/output"
```

При изменении плана обновить таймкоды и текст озвучки. Все сроки и ресурсы в презентации — инженерные оценки для испытаний, а не подтверждённые показатели готового AI-сервиса.

Исходники графики и тексты предназначены для Git; `output/` с видео/FFmpeg и `voice/` с записями исключены. При передаче комплекта на другой компьютер нужны видео, скрипты, план и подходящий FFmpeg; локальный бинарник текущего комплекта предназначен для macOS arm64.
