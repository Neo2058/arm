# Презентация ARM для руководства

Рабочая редакция от **02.11.2026**. Подготовлены две версии: **18 слайдов для пользователей и руководства**, **20 слайдов для технической аудитории**. Основание — [единый дизайн-документ](../ARM_DESIGN_DOCUMENT.md). Материалы подготовлены локально и наружу не публиковались.

## Что открыть

- [PowerPoint](ARM_Management_2026-11-02.pptx) — редактируемые тексты и блоки схем, встроенные снимки и заметки выступающего. Доступность конкретных шрифтов и переносы проверить в PowerPoint/Keynote перед выступлением.
- [PDF](ARM_Management_2026-11-02.pdf) — основная версия, 18 страниц, с объяснением пользы для машиниста, нарядчика и инструктора обычными словами. Экспортирован из HTML-компаньона, не из PowerPoint; небольшие различия компоновки между форматами возможны.
- [HTML](index.html) — автономный просмотр в браузере без интернета. Слайды переключаются стрелками/вверх-вниз страниц; можно прокручивать. При переносе сохранить рядом каталог screenshots.
- [Заметки выступающего](SPEAKER_NOTES.md) — ограничения, основания и формулировки для каждого слайда.
- Каталог previews содержит изображения всех 18 слайдов; screenshots — 9 исходных снимков. Их размеры и SHA-256 записаны в [реестре снимков](screenshots-manifest.json).

## Техническая версия сохранена отдельно

- [Техническая презентация PowerPoint](technical/ARM_Management_2026-11-02.pptx), [PDF](technical/ARM_Management_2026-11-02.pdf), [HTML](technical/index.html), [заметки](technical/SPEAKER_NOTES.md).
- Сохранены темы прежней редакции: архитектура, права сервисов, сетевая граница, ключи, копии, CI/CD и ограничения. Добавлены недостающие сценарии машиниста и поиска по колонне.
- Основная версия не требует знания устройства серверов и названий баз. Обе версии используют выражения «пользовательская проверка», «пользователи» и сохраняют разделение между работающими функциями и планами.

## Условия съёмки и достоверность

**Веб:** шесть снимков реальных представлений Laravel: карусель, сетка нарядчика, журнал, АТЗ, подстройки машиниста и записи в формуляр с личными отметками. Представления отрисованы на временной SQLite в памяти с учебными сотрудниками. HTML-снимки обслуживались локальной оболочкой, которая подставляла подготовленные ответы разделов. Это демонстрация внешнего вида, не end-to-end проверка живого сервера. Сетка заполнена учебными назначениями напрямую; снимок не подтверждает прохождение ими всех производственных правил. Все внешние запросы браузера блокировались.

**Android:** три снимка реальных компонентов журнала, АТЗ и каталога документов. Для съёмки использована отдельная демонстрационная оболочка с переключателем экранов и учебной маркировкой, а не полная штатная навигация опубликованного APK. Ответы API подставлялись локально; разрешено только чтение подготовленных маршрутов, остальные запросы блокировались. Данные журнала/АТЗ получены из той же временной Laravel-базы; каталог документов — синтетический набор.

Демонстрационный JS-пакет помещён во временную копию APK с тестовой подписью и запущен в Android-эмуляторе read-only. Wi-Fi и мобильная сеть эмулятора отключены, fetch заблокирован, Axios использует локальный адаптер. Временные файлы входа Metro удалены из mobile после съёмки; эмулятор закрыт без сохранения изменений. Опубликованный установщик не заменялся, его исходная контрольная сумма проверена после работы.

Все записи учебные: «Машинист Альфа», «Бета» и другие; реальные аккаунты, ФИО, телефоны, пароли и рабочие поручения не использовались. Съёмка не является приёмкой на физическом смартфоне. Чат, шифрование рабочих полей, закрытая сеть и помощник показаны как направления развития, а не готовые экраны. В презентации нет подключённой модели или работающего сервиса ключей.

## Источники и повторная сборка

Тексты и заметки хранятся в `tools/general-slides.json` и `tools/technical-slides.json`, собираются общим `tools/build-deck.cjs` и экспортируются в slides.json соответствующей версии. Временные зависимости устанавливались вне проекта:

```sh
npm install --prefix /private/tmp/arm-presentation-tools --no-audit --no-fund playwright pptxgenjs
node docs/management/presentation/tools/build-deck.cjs
node docs/management/presentation/tools/export-preview.cjs
node docs/management/presentation/tools/build-deck.cjs --technical
node docs/management/presentation/tools/export-preview.cjs --technical
```

Последняя команда требует локального Chrome по пути, заданному в скрипте. Инструменты рассчитаны на текущую macOS-среду; повторную сборку на другом компьютере адаптировать и заново проверить. Версии генераторов: см. [tool-versions.json](tool-versions.json).

`tools/PresentationCaptureTest.php` — отдельный локальный capture-harness на Laravel testing, а не изменение рабочих маршрутов. Не подключать его к production или общей рабочей БД. Он явно использует SQLite `:memory:`, отдельный путь окружения без проектного .env и временный storage. После создания временных каталогов его запускали отдельно:

```sh
php -d memory_limit=512M vendor/bin/phpunit --no-configuration --bootstrap vendor/autoload.php docs/management/presentation/tools/PresentationCaptureTest.php
node docs/management/presentation/tools/capture-web.cjs
```

`tools/mobile-entry.js` — исходник только демонстрационной оболочки. Для Metro его временно копировали внутрь mobile вместе с учебным `demo-api.json`, собирали отдельно и затем удаляли временные копии. Не заменять им рабочий entry point и не публиковать демонстрационный APK. Повторная нативная съёмка — отдельная процедура, не часть обычного production build.
