# Общий справочник телефонов — APK 1.0.10

Дата: 2026-10-26. Реализация: `3a3180a`.

## Что опубликовано

- Общая PostgreSQL-таблица `phone_contacts` для веба и APK. Все активные авторизованные
  пользователи могут добавлять ФИО и номер. Список общий, с поиском и страницами по 100 записей.
- Номер нормализуется перед сохранением: 8/7/10 цифр для РФ → +7;
  международный номер принимается со знаком +. Уникальный индекс запрещает дубли
  независимо от имени и одновременности запросов. Клиент получает понятную ошибку поля.
- Веб использует session + CSRF + прежние device/barrier middleware;
  APK — Sanctum + active user. Добавление ограничено 10 запросами в минуту.
- Только согласованное событие `phone.created`: ID контакта и автора, без имени/номера.
- Старые `naryad_phones` браузера сохранены. Кнопка просмотра позволяет выбрать запись
  в форму, проверить и добавить явно: автоматической публикации демонстрационных данных нет.
- Пользовательские удаление/исправление и массовая очистка общего справочника не доступны.
  Новые события аудита административных исправлений/удалений пока не включены.
- Финансовые формулы, веб-карусель и доступ к документам не менялись.

## Ручная проверка

1. Установить APK поверх приложения; внизу профиля проверить версию 1.0.10.
2. Открыть «Наряды → значок телефона», добавить настоящий контакт.
3. На другом аккаунте/устройстве и в вебе «Наряды → Телефоны» обновить список и найти его.
4. Попробовать тот же номер через 8/+7 под другим именем: должна появиться ошибка дубля.
5. Проверить поиск и звонок на физическом телефоне.

Для отката приложения использовать исправляющий APK с более высоким versionCode.
Общий справочник не удалять миграцией down после появления пользовательских контактов;
данные сохранить и корректировать вперёд. Финансовые разделы остаются отложенными.
