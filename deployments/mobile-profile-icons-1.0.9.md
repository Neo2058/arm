# Мобильные иконки и профиль Telegram — 1.0.9

Статус: опубликовано; ручная проверка реальной привязки Telegram остаётся пользователю.

## Изменения

- APK 1.0.9, Android versionCode 10: новый launcher icon, единые SVG-иконки вкладок и действий.
- Профиль: статус Telegram, привязка через существующего бота, отвязка с подтверждением,
  обновление статуса при возврате из Telegram; номер версии внизу профиля.
- GET/POST/DELETE `/api/mobile/account/telegram`: Sanctum, активный пользователь,
  одноразовый токен существующего TelegramAccountLinker, throttling, no-store.
- Коммиты реализации: `e475ed7`, `e3af556`. Второй исправляет экспорт непрозрачных PNG
  генератором; финальный APK собран после исправления.
- Сервер синхронизирован также с ранее существовавшим коммитом `79c6e4a` доступа к учёту.
  Финансовые формулы этой работой не изменялись. Миграции и смена ключей не требовались.
