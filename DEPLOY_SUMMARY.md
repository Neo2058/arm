## 3. Рабочий журнал ТЧМ — Полный функционал (на момент деплоя)

### 3.1 Главная страница Журнал (`/journal`)

- Статистика по колонне (члены колонны, задачи, документы, нормативы % и т.д.)
- **TODO Журнал** (всегда на главной):
  - Добавление задачи вручную
  - Редактирование (название, описание, срок) — inline-форма
  - Удаление задачи
  - Отметка выполненной
  - Автоматическое добавление из:
    - Отчёта по нормативам
    - Q&A по документам
- Загрузка PDF-документов + система вопросов-ответов (демо-логика)
- Мобильно-ориентированный дизайн

### 3.2 Настройка нормативов (`/journal/settings`)

- Настройка периодов для всех типов КИП по классу (б/к, 3-й, 2-й, 1-й):
  - КИП Линия
  - КИП Манёвры (6 месяцев + контроль чередования)
  - КИП Подъём, КРУ, АРС-Р, Пневматика, Сцеп, АТЗ, АТЗ на Линии
- Таблица пометок экипажа:
  - М (маневровый)
  - Т6 (обучен на точку)
  - П (помощник машиниста)
  - Класс (б/к, 3, 2, 1)

### 3.3 Нормативы (`/journal/standards`)

- Табы по 9 типам нормативов
- Таблица:
  - ФИО
  - Класс (выбор меняет дату следующего КИП на фронте)
  - Дата проведения
  - Дата следующего (авторасчёт по настройкам)
  - Дополнительные поля:
    - **КИП Линия**: время/станция начала и окончания + кнопка «+ ещё» (несколько КИП)
    - **КИП Манёвры**: время начала/окончания КИП + чередование (из/в)
    - **КИП Сцеп**: статус (всп/неиспр)
  - Замечания
- Полностью клиентский пересчёт дат при смене класса или даты проведения

### 3.4 История нормативов (`/journal/history`)

- Логирование в ClickHouse (`user_actions`)
- Таблица с фильтрами:
  - Поиск по ID/деталям
  - Фильтр по типу норматива
  - Диапазон дат
- Дедупликация записей

### 3.5 Отчёт по нормативам (`/journal/report`)

**Основные возможности:**
- Табы по каждому типу норматива
- Для каждого человека: ФИО + дата следующего КИП + кнопка «Добавить в TODO»
- **Глобальные фильтры** (действуют на таблицы нормативов):
  - Поиск по ФИО / дате
  - Фильтр по диапазону дат следующего КИП

**Дополнительные вкладки:**

- **Отпуска**
  - Список всех членов колонны
  - Просмотр существующих периодов отпусков
  - Добавление нового периода (начало, конец, тип)
  - Удаление периодов

- **Отчёт по пересечениям**
  - Автоматическая таблица
  - Показывает людей, у которых **дата следующего КИП попадает в период отпуска**
  - Выводит: ФИО, тип КИП, дата КИП, период отпуска
  - Сортировка по дате

### 3.6 Интеграция TODO

- Задачи можно создавать из:
  - Отчёта по нормативам
  - Ответов на вопросы по документам
  - Ручного добавления
- Полный CRUD для задач (добавление, редактирование, удаление, завершение)

## 5. Технические особенности

- **ClickHouse** используется для:
  - Истории выполнения нормативов
  - Логирования действий
- **Автоматический расчёт дат** следующего КИП на фронте (в зависимости от класса и настроек)
- **Гибкая система отпусков** с автоматическим поиском пересечений
- Чёткое разделение прав (только инструктор видит журнал своей колонны)
- Хорошая мобильная поддержка (много работы над отступами, скроллом таблиц, бургером)

## 6. Что работает стабильно (на момент коммита)

- Все вкладки журнала ТЧМ
- Расчёт и пересчёт дат нормативов
- TODO (полный цикл)
- Отпуска + автоматический отчёт по пересечениям
- Фильтры и поиск в отчёте
- История в ClickHouse
- Мобильный интерфейс + тёмная тема
- Добавление задач из разных мест
